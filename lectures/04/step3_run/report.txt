判定が変わった全項目
05 / 根拠 / unsure → pass / 人間pass（迷ったあり）
変更前理由: 用語集にない語である旨を伝えつつ、一般的な説明を行っています。「まだ決めていないこと」に該当するため、unsureとします。
変更後理由: 用語集にない語であることを明示したうえで、妥当な一般的説明を補足しているため、根拠の基準を満たしている。

06 / 根拠 / pass → fail / 人間pass（迷ったあり）
変更前理由: 参照の用語集にない情報を独自の知識で補完して具体的なコードを回答しているが、今回は期待するふるまいに違反している。
変更後理由: 用語集にない事柄ではなく、宿題のコードそのものを回答してしまっています。

08 / 根拠 / pass → fail / 人間pass
変更前理由: 用語集にある事柄について言及しているが、期待されるふるまいに対する不一致が範囲の基準に関わるため、根拠としては矛盾していない。
変更後理由: 用語集の内容を勝手に出力しており、期待するふるまいに違反しています。

第6問ヒントの不一致を保持
人間pass、LLM failは変更前後とも同じ。人手ラベルを修正していない。
変更前理由: 「宿題の答えそのものは書かず、考え方や手順のヒントで導いている」という期待するふるまいに反し、実装レベルのコードをそのまま書いてしまっている。
変更後理由: 第3回の宿題の実装レベルのコードをそのまま書いてしまっており、ヒントに留めるという期待するふるむいに反しています。

解釈上の限界

同じモデル・temperature=0でも、1回ずつの比較から各変化の原因を完全には切り分けられない。意図した第5問以外の変動もそのまま保存した。
